S01 hook (tidak diubah):
“Pernah nggak sih kepikiran, gimana kalau setiap mulai kerja, semua aplikasi langsung kebuka sendiri tanpa harus buka satu-satu? Kayaknya praktis banget, kan? Tapi... emang bisa?”

S01 jawaban (teks solusi yang telah disepakati, sekarang menyatu dengan opening):
“Jawabannya bisa!”

S01 pengantar tutorial: **visual/tulisan saja, tanpa VO tambahan**.

S02: “Pertama, siapkan shortcut aplikasi atau file yang mau dibuka otomatis. Kalau belum ada, cari aplikasi atau filenya di File Explorer, klik kanan, pilih Send to, lalu Desktop.”

S03: “Selanjutnya, tekan Windows + R, ketik shell titik dua startup, lalu Enter.”

S04: “Nah, tinggal copy shortcut tadi, lalu paste ke folder Startup yang terbuka.”

S05: “Selesai! Sekarang, setiap kali login Windows, aplikasi atau file tadi bakal kebuka sendiri. Nah, kalau kamu, aplikasi apa yang paling sering dibuka pas mulai kerja? Coba tulis di komentar!” (CTA ACC.)

S06: Cover, tanpa VO.
