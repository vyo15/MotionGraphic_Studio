# VO

Punya folder kerjaan atau project yang hampir setiap hari kamu buka? Tapi, pernah kepikiran nggak sih, kalau folder itu bisa dijadiin drive sendiri, kayak drive C atau D? Nah, ternyata bisa, loh!

Pertama, buka folder yang mau kamu jadiin drive, terus copy alamat foldernya.

Setelah itu, tekan Windows R, ketik CMD, lalu Enter.

Ketik SUBST, kasih huruf drive yang belum dipakai, misalnya Z titik dua. Terus, paste alamat folder tadi di dalam tanda kutip, lalu Enter.

Sekarang, coba buka This PC. Nah, folder tadi udah muncul sebagai drive Z. Jadi, kamu nggak perlu masuk ke banyak folder lagi. Oh iya, drive ini bakal hilang kalau komputer di-restart, tapi data aslinya tetap aman. Gimana? Lebih praktis, kan?
