Master asli yang menjadi dasar: MotionGraphic-Studio-FULL-v1.8.1-20261122-031809.zip.

## Cara membuka editor per-scene
1. Ekstrak Master ZIP, masuk folder `MotionGraphic-Studio`.
2. `npm install` bila dependensi belum terpasang.
3. Jalankan `npm run dev` lalu buka folder video Shutdown di sidebar Remotion Studio.
4. `Full-Video` menampilkan sembilan scene. Folder `Scenes` memuat komposisi terpisah S01–S09.
5. Pilih layer dengan nama `Interactive` di komposisi untuk mengatur teks/posisi; file sumber: `src/scenes/` dan `src/components/SceneSet.tsx`.
