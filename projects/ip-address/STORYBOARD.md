## Quality gate

1. Script **dan** storyboard lengkap disetujui sebelum build.
2. Bangun dan review **scene pertama** sebagai acuan gaya. Jangan membangun scene lain sebagai final sebelum scene referensi disetujui.
3. Evaluasi 9:16, safe zone, keterbacaan HP, kesinambungan visual, cursor/UI, layer Remotion editable, frame dan jeda.
4. Scene pertama untuk greenscreen/presenter tidak menggantikan validasi realisme UI pada scene demo pertama.
5. Baru lanjut scene lain berdasarkan acuan gaya yang dikunci.
