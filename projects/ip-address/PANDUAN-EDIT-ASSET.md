# Panduan edit — Belajar IP Address

1. Source asli ada di `projects/ip-address/src/`; aset asli ada di `projects/ip-address/public/`.
2. Edit judul, posisi, warna, durasi, dan layer sesuai komponen/config tersedia. Tidak semua elemen otomatis draggable.
3. Jika mengubah `public/`, jalankan `npm run sync` agar mirror `public/videos/ip-address/` diperbarui.
4. Preview dan render menggunakan sumber source yang sama.
5. `npm run zip -- IPAddressReels` membuat ZIP sumber editable project ini.
