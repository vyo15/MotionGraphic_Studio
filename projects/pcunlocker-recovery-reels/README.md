# PCUnlocker — Reset Password Windows

Add-on untuk MotionGraphic Studio v2.0.0 (Remotion 4.0.538). Tidak berisi Master atau renderer lain.

1. Ekstrak folder `pcunlocker-recovery-reels` ke `MotionGraphic-Studio/projects/`.
2. Di root Master, jalankan `npm run sync`, lalu `npm run dev`.
3. Buka `PCUnlockerRecoveryReels` atau komposisi `PCUnlockerRecoveryReels-S02`. Gunakan VO Guide untuk latihan setelah motion ACC.
4. `npm run addon:validate -- projects/pcunlocker-recovery-reels --strict --syntax` dan `npm run qa:native -- projects/pcunlocker-recovery-reels`.

73,1 detik (2193 frame), 1080×1920, 30 fps; 12 segment. S02 mengikuti Memory Gallery 09 yang disetujui. Preview MP4 eksternal adalah gabungan video referensi terdahulu + opsi 09; source Remotion ini rekonstruksi vektor dari referensi, bukan render yang sama. Belum ada bundling, render native, maupun uji drag/Save/reload Windows.

VO/caption mengikuti data aktual preview sebelumnya, bukan parafrase jawaban chat; opening terkunci. S02 sesuai split cue opsi 09. Demo PCUnlocker adalah ilustrasi UI, tidak diuji pada aplikasi asli. Gunakan hanya perangkat sendiri atau dengan izin pemilik; pemulihan data tidak dijamin.

Revisi S10 V4: 303 frame, S09 handoff, CTA/cover bergeser 123 frame; native QA pending.

Revisi penutup ACC: CTA 9 detik, cover 4 detik, single-track VO typography, semua visual utama named native layers. Buka segmen S11/S12 untuk edit; preview ACC adalah referensi eksternal, source native belum diuji.
