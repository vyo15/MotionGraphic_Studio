# Panduan Voice-over 15 detik

| Timeline | Aksi | Contoh penggalan VO |
|---|---|---|
| 0.0–2.5 | Klik kanan | “Bikin folder baru masih lewat klik kanan?” |
| 2.5–5.0 | Ctrl + Shift + N | “Di File Explorer, tekan Ctrl Shift N.” |
| 5.0–9.6 | New folder, ketik, Enter | “Folder langsung jadi, tinggal beri nama!” |
| 9.6–13.0 | Edge InPrivate | “Bonus! Di Chrome atau Edge, kombinasi ini membuka mode privat.” |
| 13.0–15.0 | Ringkasan | “Satu shortcut, dua fungsi.” |

Narasi persis dari script pengguna dapat direkam dan disunting agar sinkron; teks di atas hanya referensi pacing. SFX disiapkan tanpa voice-over.
