# Windows Hacks 02 — Ctrl + Shift + Esc | Windows 11 Task Manager PRO

Project add-on siap pakai untuk MotionGraphic Studio v1.6.

- Composition ID: `WindowsShortcutCtrlShiftEscProV2`
- Slug: `windows-shortcut-ctrl-shift-esc-pro-v2`
- Durasi: 10 detik (30 fps)
- Edit source: `src/` (bukan mirror di root Studio).
- Edit aset asli: `public/` (jika ada), kemudian `npm run sync` dari Master.
- Render: `npm run render -- WindowsShortcutCtrlShiftEscProV2` dari Master.
- Ekspor add-on: `npm run zip -- WindowsShortcutCtrlShiftEscProV2` dari Master.

`src/Video.tsx` diekspor sebagai `Video` tanpa mengubah perilaku animasi aslinya.
