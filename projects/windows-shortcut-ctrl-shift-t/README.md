# Shortcut Windows — Ctrl + Shift + T

Project add-on siap pakai untuk MotionGraphic Studio v1.6.

- Composition ID: `WindowsShortcutCtrlShiftT`
- Slug: `windows-shortcut-ctrl-shift-t`
- Durasi: 9 detik (30 fps)
- Edit source: `src/` (bukan mirror di root Studio).
- Edit aset asli: `public/` (jika ada), kemudian `npm run sync` dari Master.
- Render: `npm run render -- WindowsShortcutCtrlShiftT` dari Master.
- Ekspor add-on: `npm run zip -- WindowsShortcutCtrlShiftT` dari Master.

`src/Video.tsx` diekspor sebagai `Video` tanpa mengubah perilaku animasi aslinya.
