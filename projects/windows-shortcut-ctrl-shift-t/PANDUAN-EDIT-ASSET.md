# Panduan edit — Shortcut Windows — Ctrl + Shift + T

1. Source asli ada di `projects/windows-shortcut-ctrl-shift-t/src/`; aset asli ada di `projects/windows-shortcut-ctrl-shift-t/public/`.
2. Edit judul, posisi, warna, durasi, dan layer sesuai komponen/config tersedia. Tidak semua elemen otomatis draggable.
3. Jika mengubah `public/`, jalankan `npm run sync` agar mirror `public/videos/windows-shortcut-ctrl-shift-t/` diperbarui.
4. Preview dan render menggunakan sumber source yang sama.
5. `npm run zip -- WindowsShortcutCtrlShiftT` membuat ZIP sumber editable project ini.
