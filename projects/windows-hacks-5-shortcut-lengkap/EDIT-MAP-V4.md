## Panduan pengaturan

Setiap layer punya `x`, `y`, `scale`, `scaleX`, `scaleY`, `rotation`, `opacity`, `enabled`, `zIndex`, `startFrame`, `endFrame`, `animation`, `delayFrames`, `animationFrames`, dan `hueShift`.

- **loading bawah**: cari `Loading Demo · Jalur` dan `Loading Demo · Garis Bergerak` pada scene 01–05.
- **loading seri**: cari `Progress · Jalur Bawah` dan `Progress · Isi Bergerak`; footer mempunyai label teks terpisah.
- **loading HOOK**: cari `Progress Hook · Jalur` dan `Progress Hook · Isi`.
- **tahapan folder**: scene 05 memiliki 4 tahap individual dan progress garisnya.
- **snipping dashboard**: scene 03 punya 3 progress bar UI Design, Development, Testing terpisah.

Teks diubah melalui `sceneEditor → [scene] → copy`, bukan dengan mengedit JSON layer.

**Tidak ada dukungan universal drag-and-drop otomatis** untuk semua elemen nested tanpa API Interactive atau editor visual. File komponen tetap sumber edit yang sah.
