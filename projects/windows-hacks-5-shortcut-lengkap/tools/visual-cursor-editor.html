Editor tambahan pada project yang sama · drag titik klik → Simpan → preview dan render konsisten

SHORTCUT / SCENE

Pilih scene → aktifkan kursor pengganti → drag titik A (awal) dan B (akhir) di layar. Klik Render frame untuk melihat frame asli dari Remotion.
Pilih sceneFrame 0
Klik “Render frame asli” untuk melihat screenshot dari komposisi Remotion. Titik A dan B dapat digeser tanpa gambar; gambar akan dimutakhirkan setelah disimpan dan dirender ulang.
A = posisi awal · B = posisi akhir · Koordinat mengikuti kanvas 1080×1920, bukan posisi browser. Editor ini hanya mengatur kursor/klik pengganti; semua layer UI lain masih diedit melalui Remotion/Easy Editor.

KURSOR & KLIK — DETAIL

Setelah disimpan, kursor asli disembunyikan hanya dalam interval yang ditentukan. Titik klik mengikuti kursor pengganti, sehingga ring tidak akan melenceng.
Tidak termasuk fitur pemotongan klip seperti CapCut. Untuk timing narasi, gunakan 5 potongan aksi per shortcut yang sudah ada di timeline Remotion.
