## Golden-scene approval checklist

- [ ] Script keseluruhan HOOK–CTA disetujui pengguna.
- [ ] Storyboard keseluruhan disetujui pengguna.
- [ ] **Scene 00 Hook** ditampilkan sebagai preview nyata dari source Remotion dan direvisi hingga pengguna menyetujui.
- [ ] Brand kit (warna, font, spacing), gerak, timing, safe zone, peran presenter/greenscreen disimpan sebagai acuan gaya.
- [ ] **Scene 01** direview sebagai standar realisme UI browser/Windows, karena scene Hook tidak menguji UI demo.
- [ ] Baru bangun/memperbarui scene lainnya sesuai acuan approved.
- [ ] Setelah voice-over asli tersedia, sync timing dan tahan hasil demo agar mudah dipahami.
- [ ] QA semua scene plus full, cek editability di Studio, uji persistensi, render MP4 jika tersedia.

**Visual target ≠ source saat ini.** Source masih memakai durasi, teks, dan animasi lama; ini rencana revisi yang membutuhkan approval.
