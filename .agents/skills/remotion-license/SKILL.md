# MotionGraphic Studio local adapter: remotion-license

Use this skill only to FIND current official Remotion licensing terms; do not present a project-specific legal conclusion as a fact.
- Source: https://www.remotion.dev/docs/license
- License terms and conditions may change; verify the official current page before answering commercial use, business size or redistribution questions.
- Remotion code and third-party images, music and fonts may have different licenses; check each asset separately.
- This reference skill is a local supplement because the official `remotion-dev/skills` repository currently lists twelve installable directories, while the public skill documentation also names `remotion-license`.
