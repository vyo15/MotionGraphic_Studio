# MotionGraphic Studio local adapter: remotion-studio

Launch only the existing Master with `npm run dev`.
- Remotion preview is served at http://localhost:3000; the Master's independent no-code editors can be accessed at http://localhost:4077 and http://localhost:4077/visual.
- Folder-first composition registration is generated by `npm run sync`; direct edits to generated Root are not persistent.
- Verify each scene at relevant frames, not just frame 0. Confirm safe zones and that layered content does not obscure UI simulations.
- Test text edit, drag, resize, save, and reload in actual Studio before claiming a layer is visually editable.
