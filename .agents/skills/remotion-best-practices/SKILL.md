# remotion-best-practices

MotionGraphic Studio local adapter: referensi singkat untuk workflow Master v1.8.

Gunakan `useCurrentFrame`, `interpolate`, `spring`, `Sequence`, deterministik menurut frame. Pisahkan hook, editor props dan animasi. Jangan campur durasi preview dan render.

Sumber resmi yang dapat dipasang terpisah: https://github.com/remotion-dev/skills .
