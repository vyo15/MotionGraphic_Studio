# MotionGraphic Studio local adapter: remotion-maps

Use editable SVG/HTML layers for simple geographic diagrams and route highlights; add specialized libraries only if verified present in Master.
- Distinguish accurate geographic geometry from illustrative nongeographic diagrams.
- Track route points, label placements, map transforms and timing as source-configurable values.
- Keep overlays legible in vertical safe zones and avoid flattening labels into a map screenshot when editing is needed.
- Where map tiles or mapping tokens are needed, document dependencies and terms separately; do not embed secrets.
