# Font Library — Poppins / Inter / Manrope
Font utama Poppins (400–900), Inter 100–900 untuk VO Guide/teknis, Manrope 200–800 alternatif. Sumber resmi Google Fonts, SIL OFL 1.1. Binary font belum tersedia dalam patch ini; unduh sekali pada PC dengan `node tools/font-library.mjs --install`. Installer menyimpan sumber, lisensi dan hash ke `library/fonts/official/`, menolak overwrite jika sudah terpasang, gagal tanpa mengubah aset apabila jaringan gagal. `npm run dev` hanya menyalin pack ke project baru yang memilih `designContract: "compact-balanced-v1"` dengan placeholder LocalFonts resmi; scaffold juga melakukannya. Tidak ada unduhan font saat render. Jangan menyalin font komersial OS ke Master. Folder project memuat copy font legal dan lisensi, sehingga render tidak bergantung library atau OS. Alias `MG Poppins`, `MG Inter`, `MG Manrope` mencegah perubahan font pada video lama. Draft boleh fallback (status bukan review); review gagal jika font belum tersedia. Setelah download, backup Master melalui alur normal. Font bukan bagian dari ZIP patch ini.
