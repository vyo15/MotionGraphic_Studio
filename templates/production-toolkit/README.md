# Production Toolkit v1.0

Copy only needed files into an ADD-ON (no imports across projects). See `docs/PRODUCTION-TOOLKIT.md` in Master. Original generic SVG/React assets and procedural short sound cues authored for this upgrade, available to reuse in your projects. The library is NOT a Windows UI replica, a second renderer or native-editability certification. Examples are illustrative, not ready-to-render add-ons. Use actual manifest, narration hash, asset paths and editable blueprints. No third-party media included. No auto installation into old projects.
