# Production Toolkit v1.0 — Master 2.0.0

Satu Master Remotion, tidak ada renderer/dependency baru. Untuk VIDEO BARU saja, jangan retrofit ACC. `templates/production-toolkit/` adalah library source yang dipilih lalu disalin ke add-on, bukan import lintas root. `Motion Direction v3.0`, `focus-driven-v1` dan `studio-direct-v4` tetap berlaku. Tidak ada klaim native editing otomatis, ASR terpasang, atau DOM collision otomatis.

## 1. Camera & assets
Copy file yang dibutuhkan, dengan path relatif `src/animations/camera.mjs` + `camera.d.mts`, `src/components/PortraitCamera.tsx` dan opsional `WorldAssets.tsx`. Jangan overwrite source existing. Camera keyframe global (frame integer unik, `value:{cx,cy,zoom}`, easing `linear|smooth|out|hold` pada key tujuan); zoom adalah px output per px world. `fitCamera(target, viewport, padding, maxZoom)` menghasilkan pose uniform. `cameraAt` clamp di luar key, `projectRect` menghitung posisi output, `cameraTransform` menghasilkan transform lokal viewport. World UI & cursor berada dalam wrapper, subtitle/background di luar. `sceneOffset=0` di full timeline; untuk scene di dalam Sequence/SegmentVideo gunakan startFrame global yang sama untuk keduanya. Jangan mount world dua kali ketika masih berkesinambungan. Camera fit → zoom detail → pan → reframe dialog → hold → zoom out hanya bila diperlukan. Jangan gunakan Slide Mask dekoratif. Crop teknis viewport bukan transisi. Periksa target lengkap dan subtitle tidak tertutup. Kamera ini source/props-editable; child native call-sites harus dibuat literal unik sesuai blueprint dan diuji Save/reload. Generic vector assets bukan replika Windows versi tertentu: adaptasi berdasarkan UI yang benar, bukan demo palsu. Copy hanya aset yang dipakai, tidak wajib semua. SFX sintetis original WAV mono PCM16 48kHz di `public/audio/sfx/`; tidak ada rekaman pihak ketiga; cue/omit sesuai Sound Direction, volume diuji dengan VO, bukan default bunyi tiap beat.

## 2. Spatial plan: lintasan deklaratif per frame
`production/spatial-plan.json` wajib pada gate eksplisit `--production` untuk video baru; optional legacy. `narrationHash` sama dengan Motion Plan. Setiap track: `id`, `space` (`world|screen`), `worldId` untuk world, `protected` boolean, `start` inklusif `end` eksklusif global frame, `keys:[{frame,value:{x,y,w,h},ease?}]` yang mencakup rentang aktif. `protected=true` untuk informasi penting, target, subtitle; elemen dekoratif/background tidak wajib dicatat. Semua objek yang berpotensi menutup fokus dicatat. Track aktif berarti terlihat; pecah rentang bila hide. World: `{id,viewport:{x,y,w,h},keys:[{frame,value:{cx,cy,zoom},ease?}]}`; gunakan key yang sama dengan source kamera, jangan menebak posisi. Camera keys wajib mencakup boundary awal/akhir eksklusif setiap beat kamera dan cocok dengan pose awal/akhir serta focusSamples Motion Plan; minimal satu protected track beririsan setiap beat. Viewport dan `safeRect` di output px, aman dari UI Reels. `allowedOverlaps:[{a,b,reason}]` hanya overlap asli UI/parent-child yang disengaja dan diperiksa. Bukan pengecualian global. Split track bila izin berlaku pada bagian tertentu saja. Hasil validator memeriksa semua frame integer atas track yang dideklarasikan: clipping, overlap rectangle, safe zone. Boundary yang hanya bersentuhan bukan overlap. Tidak membuktikan piksel/DOM, opacity, shape, text metrics, atau source benar-benar mengikuti plan; tetap cek render. Jangan mengubah hash atau exemption hanya untuk membuat PASS. Source plan review ulang setelah Studio Save. `npm run qa:spatial -- projects/<slug>`. Contoh file `templates/production-toolkit/examples/spatial-plan.example.json` hanya ilustrasi; hash wajib diganti dengan hash beat aktual melalui `qa:motion -- <folder> --fingerprint`.

### Optional measured geometry trace
`npm run qa:spatial -- projects/<slug> --trace measured.json` checks both the planned geometry and actual supplied screen-space rects. Use `templates/production-toolkit/examples/capture-spatial-frame.js` as a read-only browser helper with explicit composition root and `data-qa-track` IDs on DOM/SVG layers. Capture after the frame is settled; coordinates are converted from the scaled preview back to output px. Save `schemaVersion:1`, `narrationHash`, `width`, `height`, `fps`, `source` (describe capture method), `frames:[{frame,rects:[{id,x,y,w,h}]}]`, ordered with unique integer frame numbers. All declared active tracks must be measured on captured frames. `sampled-only` is not proof of all frames; `all-frames` requires every frame. The helper does not advance Remotion or render automatically; capture at actual frame/Studio view is manual or external. It does not infer text visibility, arbitrary SVG occlusion, stacking context, or guarantee provenance. Inspect contact sheet/render in addition. Do not tag invisible/hidden elements as active. Technical viewport crop is allowed only outside protected target.

## 3. VO Alignment
Setelah motion ACC dan rekaman ada, siapkan JSON timestamp frasa dari transkripsi/manual alignment. `schemaVersion:1`, `narrationHash`, `audioDurationMs`, `phrases:[{beatIndex,text,startMs,endMs}]`. Urut, non-overlap, tidak melampaui durasi audio. Seluruh frasa per beat harus sesuai naskah setelah normalisasi tanda baca/case; perubahan kata harus dibahas, bukan diabaikan. Silent/cover tidak diberi frasa. `npm run vo:align -- projects/<slug> path/to/phrases.json` menghasilkan proposal frame ke stdout. Alternatif: ganti `phrases` dengan `words:[{text,startMs,endMs}]` dari transkripsi ber-timestamp eksternal; CLI memetakan kata secara otomatis ke beat bila urutan token cocok persis (tanpa mengarang waktu). Bukan ASR, bukan retime otomatis. Tinjau selisih timing, dialog/aksi, hold, segmen, subtitle, SFX bersama rekaman asli. Jangan mengubah ACC secara otomatis, jangan mengklaim synced sampai preview dan listening QA. Tidak menginstal ASR atau upload suara ke layanan luar. Contoh `templates/production-toolkit/examples/phrases.example.json`.

## 4. Approval & QA
`npm run qa:approval` read-only. Hanya exact ID dan alias pendek S01 yang cocok dengan prefix ID manifest yang diizinkan, bukan urutan scene. Duplikat/konflik tidak diwariskan. Metadata timing yang berbeda perlu review; tidak menulis state. Dashboard generated melalui sync. `qa:render` membedakan declared hold dari kandidat dead zone hanya bila manifest/plan/hash/FPS/frame cocok; hold tetap membutuhkan inspeksi visual dan tidak otomatis lulus. Gate produksi tunggal `npm run addon:validate -- <folder-addon> --production --syntax` mencakup motion/spatial/native/sound; gunakan validator individual untuk diagnosis dan `release:check` untuk pemeriksaan Master. Lanjutkan preview full/segment → ACC → VO guide/record → `vo:align` proposal → sync → render/listening QA sesuai `PRODUCTION-RULES.md`. Legacy tidak dipaksa migrasi. Tidak ada perubahan pada source project ACC oleh upgrade toolkit ini.
