# Production Toolkit v1.0 — Master 2.0.0

Satu Master Remotion, tidak ada renderer/dependency baru. Untuk VIDEO BARU saja, jangan retrofit ACC. `templates/production-toolkit/` adalah library source yang dipilih lalu disalin ke add-on, bukan import lintas root. `Motion Direction v3.0`, `focus-driven-v1` dan `studio-direct-v4` tetap berlaku. Tidak ada klaim native editing otomatis atau ASR terpasang. Geometry + visual intelligence wajib pada review video baru; runtime capture tetap mode QA terpisah, legacy tidak dipaksa. Lihat bagian Spatial Intelligence.

## 1. Camera & assets
Copy file yang dibutuhkan, dengan path relatif `src/animations/camera.mjs` + `camera.d.mts`, `src/components/PortraitCamera.tsx` dan opsional `WorldAssets.tsx`. Jangan overwrite source existing. Camera keyframe global (frame integer unik, `value:{cx,cy,zoom}`, easing `linear|smooth|out|hold` pada key tujuan); zoom adalah px output per px world. `fitCamera(target, viewport, padding, maxZoom)` menghasilkan pose uniform. `cameraAt` clamp di luar key, `projectRect` menghitung posisi output, `cameraTransform` menghasilkan transform lokal viewport. World UI & cursor berada dalam wrapper, subtitle/background di luar. `sceneOffset=0` di full timeline; untuk scene di dalam Sequence/SegmentVideo gunakan startFrame global yang sama untuk keduanya. Jangan mount world dua kali ketika masih berkesinambungan. Camera fit → zoom detail → pan → reframe dialog → hold → zoom out hanya bila diperlukan. Jangan gunakan Slide Mask dekoratif. Crop teknis viewport bukan transisi. Periksa target lengkap dan subtitle tidak tertutup. Kamera ini source/props-editable; child native call-sites harus dibuat literal unik sesuai blueprint dan diuji Save/reload. Generic vector assets bukan replika Windows versi tertentu: adaptasi berdasarkan UI yang benar, bukan demo palsu. Copy hanya aset yang dipakai, tidak wajib semua. SFX sintetis original WAV mono PCM16 48kHz di `public/audio/sfx/`; tidak ada rekaman pihak ketiga; cue/omit sesuai Sound Direction, volume diuji dengan VO, bukan default bunyi tiap beat.

## 2. Spatial plan: lintasan deklaratif per frame
`production/spatial-plan.json` wajib pada gate eksplisit `--production` untuk video baru; optional legacy. `narrationHash` sama dengan Motion Plan. Setiap track: `id`, `space` (`world|screen`), `worldId` untuk world, `protected` boolean, `start` inklusif `end` eksklusif global frame, `keys:[{frame,value:{x,y,w,h},ease?}]` yang mencakup rentang aktif. `protected=true` untuk informasi penting, target, subtitle; elemen dekoratif/background tidak wajib dicatat. Semua objek yang berpotensi menutup fokus dicatat. Untuk designContract compact-balanced-v1 tentukan role semantik pada semua track (`visual` hanya kompatibilitas legacy), guide screen/protected, zona dan gap min 80 px per frame sesuai Design System; hanya beat spoken memiliki 1 guide. Track aktif berarti terlihat; pecah rentang bila hide. World: `{id,viewport:{x,y,w,h},keys:[{frame,value:{cx,cy,zoom},ease?}]}`; gunakan key yang sama dengan source kamera, jangan menebak posisi. Camera keys wajib mencakup boundary awal/akhir eksklusif setiap beat kamera dan cocok dengan pose awal/akhir serta focusSamples Motion Plan; minimal satu protected track beririsan setiap beat. Viewport dan `safeRect` di output px, aman dari UI Reels. `allowedOverlaps` video baru wajib memakai `{a,b,type,startFrame,endFrame,reason}` sesuai kontrak layer di bawah; format `{a,b,reason}` hanya legacy. Jangan gunakan izin global untuk video baru. Hasil validator memeriksa semua frame integer atas track yang dideklarasikan: clipping, overlap rectangle, safe zone. Boundary yang hanya bersentuhan bukan overlap. Tidak membuktikan piksel/DOM, opacity, shape, text metrics, atau source benar-benar mengikuti plan; tetap cek render. Jangan mengubah hash atau exemption hanya untuk membuat PASS. Source plan review ulang setelah Studio Save. `npm run qa:spatial -- projects/<slug>`. Contoh file `templates/production-toolkit/examples/spatial-plan.example.json` hanya ilustrasi; hash wajib diganti dengan hash beat aktual melalui `qa:motion -- <folder> --fingerprint`.

### Optional measured geometry trace
`npm run qa:spatial -- projects/<slug> --trace measured.json` memeriksa deklarasi dan trace pengukuran yang diberikan. Trace v1/v2 legacy hanya untuk diagnosis; video review baru memakai v3 (lihat kontrak di bawah). Semua frame aktif yang diminta harus tercatat. Jangan menyamakan pengukuran AABB, Range atau browser hit-test dengan glyph/pixel atau provenance render.


## 3. VO Alignment
Setelah motion ACC dan rekaman ada, siapkan JSON timestamp frasa dari transkripsi/manual alignment. `schemaVersion:1`, `narrationHash`, `audioDurationMs`, `phrases:[{beatIndex,text,startMs,endMs}]`. Urut, non-overlap, tidak melampaui durasi audio. Seluruh frasa per beat harus sesuai naskah setelah normalisasi tanda baca/case; perubahan kata harus dibahas, bukan diabaikan. Silent/cover tidak diberi frasa. `npm run vo:align -- projects/<slug> path/to/phrases.json` menghasilkan proposal frame ke stdout. Alternatif: ganti `phrases` dengan `words:[{text,startMs,endMs}]` dari transkripsi ber-timestamp eksternal; CLI memetakan kata secara otomatis ke beat bila urutan token cocok persis (tanpa mengarang waktu). Bukan ASR, bukan retime otomatis. Tinjau selisih timing, dialog/aksi, hold, segmen, subtitle, SFX bersama rekaman asli. Jangan mengubah ACC secara otomatis, jangan mengklaim synced sampai preview dan listening QA. Tidak menginstal ASR atau upload suara ke layanan luar. Contoh `templates/production-toolkit/examples/phrases.example.json`.

## 4. Approval & QA
`npm run qa:approval` read-only. Hanya exact ID dan alias pendek S01 yang cocok dengan prefix ID manifest yang diizinkan, bukan urutan scene. Duplikat/konflik tidak diwariskan. Metadata timing yang berbeda perlu review; tidak menulis state. Dashboard generated melalui sync. `qa:render` membedakan declared hold dari kandidat dead zone hanya bila manifest/plan/hash/FPS/frame cocok; hold tetap membutuhkan inspeksi visual dan tidak otomatis lulus. Gate produksi tunggal `npm run addon:validate -- <folder-addon> --production --syntax` mencakup motion/spatial/native/sound; gunakan validator individual untuk diagnosis dan `release:check` untuk pemeriksaan Master. Lanjutkan preview full/segment → ACC → VO guide/record → `vo:align` proposal → sync → render/listening QA sesuai `PRODUCTION-RULES.md`. Legacy tidak dipaksa migrasi. Tidak ada perubahan pada source project ACC oleh upgrade toolkit ini.

## Spatial Intelligence — Foundation & Advanced Visual Intelligence (Paket 01/02)

**Satu renderer, tidak ada forced layout.** `contracts/spatial-profiles.json` tetap legacy 250/350/50/50 dan compact 280/350/120/160; resolver memvalidasi referensi, margin, visual region, guide dan gap. Starter memiliki token lokal yang diuji terhadap profil; perubahan style untuk project ACC tidak dilakukan. Safe-area MP4 adalah kandidat piksel, bukan aturan resmi platform.

### Kontrak layer video baru
- `production/spatial-plan.json`: `geometryContract: "screen-space-v1"`, `intelligenceContract: "visual-intelligence-v1"`, `schemaVersion: 1`. Review production gate menolak kontrak hilang. Legacy tanpa kontrak tetap tidak dimigrasikan.
- Setiap track memakai role spesifik: background, container, headline, text, primary-object, secondary-object, ui-control, dialog, cursor, connector, subtitle, transition, vo-guide. `native: true` + `nativeName` unik harus cocok dengan literal `name` dan `data-qa-track` pada satu `Interactive` call-site; `native:false` memakai literal marker DOM/SVG biasa. Semua native target blueprint tetap wajib tercatat. `source` path relatif `src/...tsx` opsional; AST mengisi lokasi bila tidak dideklarasikan dan menolak mismatch. Background tidak otomatis bebas occlusion jika ternyata di depan. `parentId` menunjuk track yang aktif mencakup child; siklus ditolak.
- Aktif `[start,end)` global frame; `visibility: visible|mounted` eksplisit. `hiddenFrames` untuk frame yang sengaja tidak tampak, `fadeRanges:[{start,end}]` untuk rentang fade terencana; jangan pakai untuk menyembunyikan kegagalan. Protected layer selain fade wajib tampak. `minOpacity` opsional, default .05 sebagai indikator visibility, bukan ambang keterbacaan. `textRequired:true` untuk UI control dengan teks, otomatis pada headline/text/guide/subtitle; `minFontSize` dalam reference px, `maxLines`, `fontFamily` (nama family pertama yang diharapkan) dan `minGap` dapat ditetapkan sesuai hierarchy. Text layout, line count, font scale dan contrast estimates bukan glyph mask.
- `allowedOverlaps` memerlukan `a,b,type,startFrame,endFrame,reason`; end eksklusif, berada pada irisan kedua track. Type: containment, interaction, transition, connector, dialog, other. Containment perlu container/dialog dan child di dalam bounds; izin overlap bukan izin menutup protected text, keluar viewport atau melanggar safe zone. Legacy exception masih diterima untuk plan lama.
- `interactions` opsional untuk video tanpa cursor; cursor wajib event atau `cursorPurpose: "navigation"`. Event: `id,type: click|double-click|drag|selection,cursorId,targetId,frame`; non-click perlu `endFrame`, opsional `endTargetId`. Marker hotspot `data-qa-hotspot` berada tepat di ujung pointer; bukan pusat gambar pointer. `requireActionMarker:true` mengharapkan `data-qa-action=<event id>` pada cursor pada frame aksi; untuk response opsional `{layerId,startFrame,endFrame,state:"visible"|"hidden",beforeState?,value?}` dengan `data-qa-state` jika `value` dipakai. `soundCueId` opsional mengacu pada cue ready/omit; ready harus impactFrame = frame klik. Ini metadata sound, bukan listening QA.
- `riskWindows:[{start,end,reason,step?}]` untuk spring overshoot, typing, crossfade, atau transform yang tidak diwakili keyframe; step 1–5, end eksklusif. Sampler menambah frame sekitar beat/scene, action/response/hold, keyframe, camera, fade, risk window dan cue. Sampling lebih rapat, tetap bukan bukti semua frame. Full scan masih tersedia.

### Capture & evidence
Starter memakai `src/qa/SpatialProbe.tsx` dan helper v3 lokal (canonical copy `templates/production-toolkit/examples/capture-spatial-frame.js`); probe render-only, tidak menulis DOM/source. Root `data-qa-root="composition"` tunggal axis-aligned; offset segment global sesuai manifest. Tunggu font lokal termasuk descendant dan dua RAF; font MG faces terdaftar/loaded tidak membuktikan glyph tertentu menggunakan face yang dimaksud. Trace mengukur raw/visible AABB, clipping parent persegi, text Range per baris dan visible rectangles, computed font metrics, estimasi scale/contrast, opacity, marker hotspot, sampled hit order, dan quad konveks bila benar-benar tersedia. Complex paint (mask/filter/clip-path, arbitrary SVG/rotation, pointer-events:none, shadow/transparent/gradient, untracked overlays) masih memerlukan review visual; differential pixel review terbatas tersedia (lihat Final A–E), bukan pixel-mask engine presisi. Solid full-cover dapat dilaporkan sebagai FAIL geometri; partial/uncertain paint sebagai WARNING, tidak disembunyikan oleh izin overlap.

`trace.json` v3 menyimpan requested frames, scope full/segment, input props dan preset, fingerprint input, identitas browser dari userAgent, versi probe dan environment. Source berubah selama capture menghasilkan STALE; membandingkan browser lintas sesi memerlukan identitas runtime pembanding, bukan sekadar membaca ulang userAgent yang tercatat. Trace sintetis dan fingerprint tidak membuktikan provenance. `PASS` = seluruh frame full composition yang diukur lulus pemeriksaan yang diterapkan, `PASS_SEGMENT` hanya segment, `PASS_SAMPLED` hanya sampel, `WARNING` kandidat review, `FAIL` pelanggaran, `INCOMPLETE` data wajib tidak tersedia/invalid, `STALE` input berubah. `--require-full` menolak trace lama, sampled, stale dan segment. `report.json` berisi kode, severity, scene/beat, frame/timecode, layer/source, interval kontinu hanya pada frame yang benar-benar diukur, dan rekomendasi. `review.html` berisi selected annotated SVG + original PNG; maksimal 42 frame event terpilih ditambah boundary scope, maksimal 120 frame masalah tambahan pada full scan, seluruh temuan tetap di JSON. QA MP4 contact sheet event-based bila metadata video cocok, fallback interval jika tidak; pilihan sheet dibatasi.

### Workflow harian
`npm run dev` tetap sync, static QA, regression, backup, Studio dan auto sampling setelah edit stabil. `npm run prod` tetap preview ringan, tanpa Master watcher. `npm run menu` → 17 → project → sample preview/full preview/full final High/declared/full CapCut serta pilot. Capture otomatis, menu dan render menggunakan lease lintas proses; menu/render menunggu maksimal 10 menit, auto mengalah dan mencoba lagi. Mode final default memakai resolver High, `--profile capcut` internal memakai resolver CapCut yang sama dengan render. Tidak ada command utama baru.

Diagnosis teknis (opsional, bukan workflow wajib):
```powershell
node tools/capture-spatial.mjs projects/<slug> --full --mode final --profile capcut --out qa-out/<slug>/capcut-full
npm run qa:spatial -- projects/<slug> --trace qa-out/<slug>/capcut-full/trace.json --require-full --mode final --profile capcut
```
`--segment <id>` mengukur frame global segment. `--compare-segment <trace.json>` pada validator full membandingkan data frame yang sama dengan konteks props/input/runtime yang cocok; tidak mengklaim pixel parity, GUI atau Save/reload. Project yang sudah memakai probe v2 perlu upgrade terarah sebelum trace v3, tanpa migrasi otomatis.

**Batas paket:** unit/regression synthetic dan declared QA terpisah dari Remotion bundling, browser, Save/reload, render MP4 asli dan listening. Runtime pilot pada PC wajib sebelum menyatakan capture v3 terverifikasi. Fitur pixel-level exact occlusion, glyph fallback per karakter, shape/mask arbitrary, contrast terhadap video bergerak, dan pembuktian visual reaksi UI kompleks belum lengkap. Phase 4/5 ditambahkan dengan batas implementasi di bawah. Jangan memberi ACC otomatis atau menggeser layout pengguna.

### Smart Layout Assistant & Automatic Quality Gate (Paket 03/04)
- `layout-advice.json` otomatis setelah capture selesai, berisi proposal read-only: koreksi delta screen-space yang diuji terhadap semua frame yang tersedia, optical center, kandidat dimensi/scale, text-fit dan batas minimum font, kandidat endpoint cursor, estimasi reading time dari narration dan review layout/timing/camera. Ini bukan transform lokal, source patch, pengukuran glyph, atau bukti bahwa semua frame aman. Sistem tidak mengubah teks, keyframe, ACC, UI Windows, atau file native; jangan menerapkan rekomendasi pada ACC tanpa izin. ChatGPT menerapkan revisi source terbatas setelah membaca checksum, scope, dan membandingkan hasil sebelum/sesudah. Opsional `layoutGroups:[{id:"headline-group",layers:["title","description"],axis:"vertical",align:"center",gap:16,frame:30}]` untuk alignment/distribusi yang memang disengaja; gap reference px, frame global, anchor ikut sampling. Tidak menduga semua kelompok atau memaksa simetri.
- `qa-out/.qa-active.lock` adalah lease eksklusif capture/render (satu pekerjaan berat), tiket manual menunggu FIFO; auto sampling mengalah jika ada tiket. Lock PID hidup tidak dihapus; lock proses yang terbukti mati dapat dipulihkan. Lock rusak/ambigu perlu pemeriksaan manual setelah semua proses berhenti. Auto sampling dibatalkan setelah perubahan input terdeteksi; tidak mengulang kegagalan yang sama kecuali busy atau input berubah. `prod` tidak menyalakan watcher. Bundle dan browser digunakan ulang dalam satu capture jika API mendukung (lihat Final A–E); benchmark CPU/RAM dan pembuktian Windows masih perlu diuji. Watcher memakai memo hash berdasarkan stat file; capture/final dan ekspor aktual membaca ulang bytes.
- `qa-out/evidence-index/` menyimpan ringkasan per project/scope/preset/request. Auto boleh melewati preview sample yang input dan checksum report/trace masih cocok; tampilkan `CACHED_SAMPLE`, **bukan PASS runtime sesi baru**. Full/final selalu capture baru. Failure terbaru menggantikan cache yang sebelumnya lulus. Handoff `CHATGPT-LATEST.zip` menyertakan `qa-evidence/` berisi ringkasan current-input, proposal terbatas, gambar masalah terpilih (maksimum 4 PNG per capture, maksimum 2 MiB per file, 12 MiB keseluruhan). Bukti stale/tampered diabaikan; seluruh trace, MP4, cache dan screenshot lain tetap lokal. Summary historis tidak membuktikan provenance browser.
- Render lewat menu/CLI: project review baru diperiksa static production gate + actual capture sesuai Preview/High/CapCut dan scope full/segment. Preview yang gagal boleh diekspor sebagai diagnostik. High/CapCut baru wajib review, full capture untuk scope yang diminta, tidak ada issue blocking, props/preset sama, fingerprint current sebelum render dan sesudahnya. `qa-render.mjs` otomatis memeriksa MP4 dan contact sheet; segment memakai offset global. Jika output gagal atau WARNING, file MP4 dipertahankan untuk diagnosis dan quality gate gagal (bukan final siap publikasi). `quality-gate.json` menyimpan SHA-256 MP4, preset, scope dan status. Legacy tidak dipaksa punya capture; post-render heuristik informatif. Source/backup tidak dilarang diekspor karena collision warning.
- `npm run menu` → 17: sample/full preview, full High, declared, full CapCut. Tidak perlu command utama baru; `dev` auto sampling, `prod` ringan, `menu` QA/render. Capture/QA otomatis bukan pengganti review kreatif, GUI Save/reload, listening, final ACC. Browser runtime pilot dan native editability nyata tetap wajib, exact glyph/pixel/mask dan responsive reflow kompleks belum lengkap; differential pixel dan plain-text reflow terbatas dijelaskan di bagian Final A–E.

### Final refinement A–E (source implementation; runtime verification pending)
- Advanced layer contract: `parentId` implies containment unless `containment:"overflow-allowed"` with `containmentReason` (e.g. popup). Protected fade ranges may touch entry/exit only; union of fade/hidden waivers may not exceed half the track. Font family compares normalized primary family exactly; optional numeric `fontWeight` is checked. Computed font metadata is not proof of the actual glyph face. New compact review requires explicit `subtitlePolicy:{preview:"required",high:"none",capcut:"none"}` or policy matching actual preset; `required` final expects final subtitle, not draft guide. Legacy unchanged.
- Object-centered: declare `objectAnchors:[{id:"hero",anchorId:"hero-object",headlineIds:["title"],start:0,end:60,gap:48,motion:"fixed"}]`. Use `data-qa-visual` on visible artwork subtree; union of bounds approximates artwork, not pixel-weighted optical balance. Default `marked` policy requires measurement; explicit `visualBoundsPolicy:"layer"` + `visualBoundsReason` only for tight artwork bounds. `motion:"motivated"` requires `reason`. New compact review with standalone primary object + headline requires anchor policy. Advisor moves headline group, never anchor; preserves guide, UI and ACC. Fixed anchor drift, gap and alignment checked on measured frames. Gap in reference px. Advice read-only.
- Probe adds bounded candidates for painted `pointer-events:none` and offscreen plain HTML text reflow measurement (axis-aligned; not rich/SVG text or complex transforms). Manual capture attempts up to three suspicious text/cover pairs with controlled isolation PNGs and repeated baseline; `precision-review.json` records differential pixel contribution, not glyph mask, never waives existing findings. Unsupported probes/formats or unstable repeat remain incomplete. Isolation frames cannot count as full evidence. Auto watcher avoids extra precision renders.
- Capture uses shared Remotion browser within a job when API available; `performance.json` records still count, duration and Node RSS (not browser/system RAM). Browser and cancellation behavior need PC verification. Full/segment comparison includes font, text and interaction metadata, not GUI/pixel parity.
- Menu 17 offers staging `spatial-qa-pilot` (four starter scenes, 600 frames, five faults). Copy staged `projects/spatial-qa-pilot` into Master only if desired; dev syncs. Capture baseline then fault variants via menu 17. Fault result requires expected issue code; missing browser is NOT_VERIFIED. Do not publish pilot or grant ACC. Native Save/reload, full/segment, MP4 and listening require PC verification.
- Menu 7 diagnostic Master ZIP: separate dated `CHATGPT-DIAGNOSTIC-*.zip`, source snapshot with `DIAGNOSTIC-NOT-PRODUCTION.json` and static failure log. Never replaces `CHATGPT-LATEST.zip` or waives gates; output filesystem must support exclusive hard-link publication (otherwise fails safely). Normal handoff retains bounded QA evidence. Diagnostic archive is source-only; provide relevant QA report separately if needed.
