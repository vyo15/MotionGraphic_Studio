# PREVIEW VIDEO OUTPUT CONTRACT — MOTION GRAPHIC

**Trigger:** pengguna meminta `preview scene`, `lihat animasi`, `coba 5 style animasi`, `perbaiki transisi`, `coba video`, atau permintaan lain yang jelas menginginkan gerakan.

1. **Output utama wajib preview benar-benar bergerak** (MP4 yang bisa diputar; GIF bergerak boleh bila relevan dan kualitas mencukupi). Gambar statis bukan video dan tidak boleh menggantikan tanpa penjelasan.
2. Video preview scene menampilkan animasi dari timeline source yang dimaksud, dengan durasi, FPS, scene ID, dan path benar; bila revisi transisi tampilkan beat sebelum & sesudahnya agar continuity terlihat.
3. Jika diminta N alternatif style untuk **animasi**, hasil yang ditargetkan adalah N alternatif gerak, bukan N gambar diam. Jika user hanya meminta konsep/storyboard, gambar dapat menjadi acuan visual.
4. Bila rendering tidak tersedia/gagal, katakan jujur **preview belum berhasil**; berikan source/diagnosis yang tersedia. Jangan menyebut contact sheet, mockup, screenshot, atau kode sebagai hasil video siap tonton.
5. Lakukan cek file ada, probe durasi, FPS, resolusi, frame tidak kosong, teks tidak terpotong, transisi dan sound (jika relevan), serta uji playback jika tersedia. Bedakan dari cek source tanpa render.
6. Preview tidak otomatis memberi ACC. Setelah pengguna menyatakan ACC, perbarui state project dan board VO/ACC melalui file change only.

Audio preview mengikuti `docs/SOUND-DIRECTION-RULES.md` dan `docs/SFX-LOCAL-FIRST.md`. Tidak ada routing audio tambahan di file ini.
