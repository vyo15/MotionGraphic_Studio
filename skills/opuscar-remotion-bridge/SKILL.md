# Opuscar → Remotion (referensi kreatif ringan)

Ini **bukan** plugin Lemo-Opuscar dan tidak menginstal renderer lain. Referensi teknik: https://github.com/lemomo-ai/lemo-opuscar.

- Windows/software: Living Screencast — UI dan kursor akurat, hasil tindakan nyata.
- SOP/prosedur: Instruction Manual — penanda urutan, objek bergerak sesuai langkah.
- Excel/KPI: Data Storytelling — satu hubungan angka per beat, grafik dari data benar.
- Jaringan/mekanisme: Precise Mechanism — aliran/paket memperagakan sebab akibat.
- Tipografi/hook: Swiss Motion — grid, hierarki, ritme presisi.

Aturan utama tetap Minimal Editorial, Remotion folder-first, satu Master, naskah draft → motion → review → VO Guide → rekam → sync → QA. Jangan menyalin aset/kode/demo/karakter/font dan jangan menambah dependensi Opuscar ke Master. Baca `contracts/creative-style-profiles.json` dan `docs/USER-FLOW-CHATGPT.md` untuk rute penggunaan.
