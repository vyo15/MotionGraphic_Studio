Atur video tanpa VS Code • Tersimpan ke folder project • Remotion tetap untuk preview & render
✥ Edit Visual — drag objek & kursor▶ Buka Remotion Studio
Ubah angka, teks, animasi, atau audio → klik Simpan Perubahan. Perubahan masuk ke motiongraphic-video.json dan otomatis tersinkron ke Remotion. Refresh tab Studio untuk melihat hasil. Untuk menggeser objek secara visual, buka Edit Visual. Penggeseran di Remotion langsung hanya tersedia untuk layer Interactive yang didukung Remotion.
