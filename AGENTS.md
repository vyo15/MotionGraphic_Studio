# MASTER RULES — Unified Production 1.0
Mulai dari `CHATGPT-READ-FIRST.md`. File ini pemilik aturan scope, prioritas, safety dan delivery; bukan pengulangan style/flow.

- Prioritas: keamanan/platform → permintaan terbaru yang eksplisit dalam scope dan keputusan ACC/LOCK yang belum dibuka → kontrak/source Master aktual → aturan produksi ini → referensi kreatif. Jika bertentangan, laporkan. Jangan menganggap keputusan ACC berubah karena versi template baru.
- Satu Master Remotion. Video baru = project mandiri `projects/<slug>/`. Registrasi lewat sync/dev. Jangan edit manual `src/Root.tsx`, `src/index.ts`, `package.json`, `library/catalog.json`, atau mirror `public/videos/` demi registrasi. Tidak membuat renderer/editor kedua, tidak menambah dependency tanpa keputusan terencana.
- Revisi hanya target diminta, pertahankan slug/ID, layer name, timing/VO/scene ACC, aset, backup, project lain dan local edits. Baca bukti source dan catatan keputusan; jangan menebak. `npm run sync` membuat kontrol produksi yang belum ada, tidak boleh reset keputusan.
- **REVISION SCOPE LOCK / ANIMATION PRESERVATION LOCK:** hanya ubah target yang diminta. Revisi layout tidak boleh mengganti animasi sumber dengan screenshot, gambar statis, video flatten, atau rekonstruksi tanpa izin. Pertahankan keyframe, easing, aset, timing lokal, font, subtitle, audio dan ACC yang tidak diminta; bandingkan source/preview sebelum–sesudah, catat pengecualian dan handoff minimum bila diperlukan.
- Delivery semua pekerjaan = satu ZIP **FILE CHANGE ONLY**: video baru berisi seluruh file BARU di `projects/<slug>/`; revisi/Master fix hanya file baru/berubah, isi lengkap dan path relatif root. Ekstrak di luar Master, cek base hash dan backup, lalu copy–paste–Replace ke root. Tidak perlu inbox, installer atau format patch native untuk flow ini. Tidak mengirim ulang Master atau file tidak berubah, tidak pakai patcher. Sertakan daftar, base hash/backup guidance, scope dan QA. Penghapusan manual hanya setelah bukti/backup; lihat `docs/ARTIFACT-HYGIENE.md`. Jangan menyentuh backup atau project ACC untuk cleanup dokumentasi.
- Mode, storyboard, motion-first dan QA mengikuti `PRODUCTION-RULES.md`. Style dan TEXT HIERARCHY & SUBTITLE LOCK v2.0 dimiliki `docs/MOTIONGRAPHIC-DESIGN-SYSTEM.md`; audio dimiliki `docs/SOUND-DIRECTION-RULES.md`. Tidak ada aturan tambahan di file ini untuk keduanya.
- Jangan klaim skill, GUI Save/reload, rendering atau listening sudah berjalan tanpa bukti. Dokumentasi pada ZIP bukan konfigurasi otomatis akun. Lapor blocker dan perbedaan static vs runtime.
